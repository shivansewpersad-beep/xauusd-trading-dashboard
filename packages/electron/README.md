# Electron Desktop Application

Professional XAUUSD trading dashboard packaged as a native desktop application.

## Features

✅ Native Windows, macOS, and Linux support  
✅ Auto-updater for seamless version management  
✅ System tray integration  
✅ Offline-capable with cached data  
✅ Hardware-accelerated rendering  

## Development

```bash
npm install
npm run dev
```

## Building

```bash
# All platforms
npm run dist

# Windows only
npm run dist:win

# macOS only
npm run dist:mac

# Linux only
npm run dist:linux
```

## Output Locations

- **Windows**: `dist/XAUUSD-Trading-Dashboard-Setup-1.0.0.exe`
- **macOS**: `dist/XAUUSD-Trading-Dashboard-1.0.0.dmg`
- **Linux**: `dist/XAUUSD-Trading-Dashboard-1.0.0.AppImage`
